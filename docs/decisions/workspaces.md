# ワークスペース

- 状態：提案中
- 関連：[UI とツール](ui.md)、[ローカルファースト](local-first.md)、Sendo の[ワークスペース](https://github.com/sendo-feed/sendo/blob/main/docs/decisions/workspaces.md)

## 決定

1. **表示は「すべて」か、選んだワークスペースの集合にする。** 初めて開いたタブは All で始まる。既存の購読が入る `default` と新規アカウントに作られる空の `default` は、ほかのワークスペースと同じように選べる。集合を選んだときはどれか1つに属するものを出し、0件選択は空の表示にする。All には未割り当てと購読のない項目も含める。選択中の名前と範囲を画面上部で確認できるようにし、切替メニューに複数選択、単独表示、All を置く。
2. **選択はタブごとに覚える。** アカウントを区別して `sessionStorage` に置き、再読み込み、オフライン起動、戻る・進むで適用する。URL と履歴の項目には選択を書かない。新しいタブの選択は独立し、ブラウザがタブを複製する場合は、複製時の選択を引き継いだあと独立して変えられる。選択先が手元の一覧から消えたら表示から外し、すべて消えたら空の表示にする。保存済みの ID は利用者が選択を変えるまで保持し、削除が拒否されて項目が戻ったときは元の選択で表示する。保存した選択が読めない場合は空の表示にして、利用者が範囲を選べるようにする。
3. **各画面で同じ範囲を使う。** 一覧、検索、最近読んだ記事、サイドバー、未読数、タブタイトル、購読管理を同じ範囲で絞る。記事は現在の有効な購読に従い、フォルダは対象内の購読があるものを出す。選択範囲が決まる前や、購読と所属先の照合が済む前は、対象だと確認できた項目だけを表示する。範囲を切り替えたら前の範囲で読み出した表示を取り除き、古い読み出しの結果を捨てる。開いている詳細、URL を直接開いたとき、履歴から戻ったときも照合し、外れたフィード・フォルダ・記事は名前や内容を表示せず、選択中の All に戻す。利用者が対象外の名前を見るには、切替メニュー、購読の所属先の選択、ワークスペースの管理のいずれかを明示的に開く。初版の切り替えには専用の固定モードを設けない。
4. **Saved は範囲を適用してから URL でまとめる。** 選択中のワークスペースでは、その範囲の有効な購読から来たスター記事を出す。購読解除後のスター記事と購読外から保存したページは All で出す。同じ URL の場合も、選択範囲に含まれるスター記事のタイトル・サムネイル・操作だけを使う。All では Saved の従来のまとめ方に従う。
5. **購読管理で所属を選べる。** 購読追加では所属先か未割り当てを確認できるようにする。閲覧で1つだけ選択しているときはそのワークスペースを初期値にする。複数選択中は所属先を明示し、All での初期値は未割り当てにする。管理から各購読を移せ、フォルダは保つ。初版では1件ずつ移す。名前も変更でき、有効な購読が残っている場合は先に移動や購読解除が必要と知らせる。ワークスペースの削除に失敗した場合は同期結果を反映する。全購読の情報を含む OPML の書き出しは All で使える。
6. **同期と書き込みは core で扱う。** `includeWorkspaces=true` で差分を取り、ワークスペースと有効な購読の ID・所属を手元に置く。古いカーソルのまま更新できる。所属先の行が別ページにある場合は揃ったあとに表示し、購読の移動やワークスペースの削除から記事を消す処理は行わない。Sendo の対応は `workspaces` を含む同期応答で判断する。対応前の Sendo でも All の閲覧と従来の操作を続けられる。選択範囲を保存済みのタブは、所属を確認できる範囲で表示を続ける。対応を確認した Sendo への作成、改名、削除、購読の移動は手元に反映して操作キューに積む。
7. **一括既読は操作時の表示範囲で固定する。** 絞り込んだ一覧では、その一覧に入る有効な購読の ID と完了した記事の同期カーソルを、押した時点で記録する。再送でも同じ購読 ID とカーソルを渡す。記事の位置・経過時間などでさらに対象を限定する操作は、既存の個別記事 ID 指定を使う。同期の境界が揃っていない場合や送信を拒まれた場合も、対象外へ広げず、表示を同期結果に戻す。表示範囲が「すべて」の場合は従来の一括既読を使う。

## 理由

- 普段は複数のワークスペースを読め、画面を共有するときは一般のフィードだけに絞り込める。タブごとの切り替えなら、別の機器やタブの読書を中断しないで済む。
- 一覧のほかに検索や履歴を絞ると、通常のページ移動や再読み込みで範囲を維持できる。
- 購読の ID を押したときに記録すると、オフラインの間に所属が変わっても一括既読の対象が広がらない。

## 検討した代替案

- ワークスペースを常に1つ表示する。普段まとめて読む用途に合わない。
- 選択を端末間で同期する。別のタブや端末からの操作で共有中の範囲が広がる。
- 専用の共有モードを設ける。初版は閲覧範囲の切替までに絞る。

## 見直す条件

- 切替メニューを開いたときも選択外の名前を伏せたいと分かったとき。
- 購読の整理で複数件の移動が繰り返し必要になったとき。
